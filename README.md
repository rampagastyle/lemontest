# 🍋 LEMON Tickets - ТЕСТОВАЯ ВЕРСИЯ

Telegram-бот для продажи и управления билетами на мероприятия (тестовая версия без реальной оплаты).

## ⚠️ Отличия от полной версии

- **Без реальной оплаты** — билеты выдаются бесплатно по подтверждению
- **Несколько билетов** — можно купить больше одного на мероприятие (бот предупреждает)
- **Подарочные билеты** - админы могут дарить билеты пользователям
- **Расширенная статистика** - куплено/подарено/использовано
- **Сканирование билетов** - админы активируют билеты по коду

## Возможности

### Для пользователей:
- 🎫 Список мероприятий со ссылкой на пост в Telegram
- 📋🚪 Выбор билета: **«По списку»** или **«Без списка»** (у каждого своя цена)
- 🆓 Бесплатное получение билета (тест), не более одного купленного билета на мероприятие
- 🎟 QR-билеты с уникальными кодами
- 💬 Техническая поддержка (обращение сохраняется в БД и приходит админам)

### Для администраторов:
- ➕ Создание мероприятия за 6 коротких шагов: название, дата, ссылка на пост, две цены, количество билетов
- 📋 Управление мероприятиями: активация/деактивация, изменение названия, даты, цен, добавление билетов
- 🎁 Выдача подарочных билетов
- 📊 Статистика: по списку / без списка / подарено / использовано / выручка
- ✅ Режим проверки билетов: сканируете QR камерой телефона, бот проверяет сам
- 👥 Управление админами

## Отличия от полной версии

- **Без реальной оплаты**: билеты выдаются бесплатно по подтверждению
- Принадлежность к списку гостей автоматически **не проверяется**: тип билета запоминается, а на входе бот напоминает сверить гостя со списком

## Установка

### 1. Клонируйте репозиторий
```bash
git clone <repo-url>
cd lemon-tickets-test
```

### 2. Установите зависимости
```bash
pip install -r requirements.txt
```

### 3. Настройте окружение
Создайте файл `.env`:
```bash
BOT_TOKEN=your_telegram_bot_token
DATABASE_URL=postgresql://user:password@host:port/database
ADMIN_IDS=123456789,987654321
```

### 4. Получение токена бота
1. Напишите @BotFather в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен в `.env`

### 5. Запуск локально
```bash
python bot.py
```

## Как проверять билеты?

QR билета — это ссылка на бота (`https://t.me/<бот>?start=t_<код>`).

1. Админ нажимает **«✅ Проверка билетов»** (включается режим проверки)
2. Сканирует QR гостя камерой телефона и открывает ссылку: Telegram переходит в бота
3. Бот сразу проверяет и активирует билет (если Telegram просит, достаточно нажать «Start»/«Отправить»)
4. Так проверяются все гости подряд, без дополнительных кнопок
5. В конце: **«⏹ Выключить проверку»**

Подробности: [SCANNING_GUIDE.md](SCANNING_GUIDE.md). Обратите внимание: у бота должен быть username (задаётся в @BotFather).

## Статистика

Бот показывает:
- **По списку / Без списка** - билеты, полученные пользователями (тест) по каждому варианту
- **Подарено** - билеты, выданные админами
- **Использовано** - активированные билеты на входе
- **Выручка** - потенциальная выручка по ценам выбранного варианта (если бы оплата была реальной)

## Типы билетов

- 📋 **По списку** - куплен по цене «По списку»
- 🚪 **Без списка** - куплен по цене «Без списка»
- 🎁 **Подарочный** - выдан администратором напрямую

## Заметки по надёжности

- Выдача билета атомарна: остаток уменьшается условным `UPDATE ... WHERE available_tickets > 0`, поэтому продать больше билетов, чем есть, нельзя. В БД добавлен `CHECK (available_tickets >= 0)`.
- База обновляется автоматически: новые поля (ссылка на пост, две цены, тип билета) добавляются миграцией при старте, старые события и билеты сохраняются.
- Активация билета на входе блокирует строку (`FOR UPDATE`): два админа не смогут одновременно пропустить один билет.
- Все админские кнопки и callback-и проверяют права.
- Состояния диалогов (FSM) хранятся в памяти (`MemoryStorage`) и сбрасываются при перезапуске бота.

## Переход на полную версию

Для добавления реальной оплаты:
1. Подключите ЮКасса или другую платежную систему
2. Замените тестовую оплату на реальную в `handlers/user_handlers.py` (функция `confirm_purchase`)
3. Добавьте webhook для подтверждения платежей

См. директорию `lemon-tickets` для версии с реальной оплатой.
