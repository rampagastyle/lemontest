# 🍋 LEMON Tickets - ТЕСТОВАЯ ВЕРСИЯ

Telegram-бот для продажи и управления билетами на мероприятия (тестовая версия без реальной оплаты).

## ⚠️ Отличия от полной версии

- **Без реальной оплаты** - билеты выдаются бесплатно по подтверждению
- **Подарочные билеты** - админы могут дарить билеты пользователям
- **Расширенная статистика** - куплено/подарено/использовано
- **Сканирование билетов** - админы активируют билеты по коду

## Возможности

### Для пользователей:
- 🎫 Просмотр доступных мероприятий
- 🆓 Бесплатное получение билетов (тест)
- 🎟 QR-билеты с уникальными кодами
- 💬 Техническая поддержка

### Для администраторов:
- ➕ Создание мероприятий
- 🎁 Выдача подарочных билетов
- 📊 Детальная статистика (куплено/подарено/использовано)
- ✅ Сканирование и активация билетов
- 👥 Управление админами

## Установка

### 1. Клонируйте репозиторий
```bash
git clone <repo-url>
cd lemon-tickets-test
```

### 2. Установите зависимости
```bash
pip install -r requirements.txt
```

### 3. Настройте окружение
Создайте файл `.env`:
```bash
BOT_TOKEN=your_telegram_bot_token
DATABASE_URL=postgresql://user:password@host:port/database
ADMIN_IDS=123456789,987654321
```

### 4. Получение токена бота
1. Напишите @BotFather в Telegram
2. Отправьте `/newbot`
3. Следуйте инструкциям
4. Скопируйте токен в `.env`

### 5. Запуск локально
```bash
python bot.py
```

## Деплой на Railway

### 1. Создайте проект на Railway
1. Зайдите на [railway.app](https://railway.app)
2. New Project → Deploy from GitHub
3. Выберите ваш репозиторий

### 2. Добавьте PostgreSQL
1. В проекте: New → Database → PostgreSQL
2. `DATABASE_URL` добавится автоматически

### 3. Настройте переменные
Добавьте в Settings → Variables:
- `BOT_TOKEN`
- `DATABASE_URL` (автоматически)
- `ADMIN_IDS`

### 4. Деплой
Railway автоматически задеплоит бота.

## Как сканировать билеты?

### Способ 1: Через бота (рекомендуется)
1. Админ нажимает "✅ Проверить билет"
2. Пользователь показывает QR-код
3. Админ копирует код под QR и отправляет боту
4. Бот активирует билет и показывает информацию

### Способ 2: Сканирование QR-кода (опционально)
Для автоматического сканирования нужно:
1. Установить приложение для сканирования QR (например, "QR Scanner" на телефон)
2. Отсканировать QR-код билета
3. Скопировать полученный код
4. Отправить код боту через "✅ Проверить билет"

### Способ 3: Мобильное приложение (будущее)
В планах создать отдельное мобильное приложение для:
- Автоматического сканирования QR-кодов камерой
- Мгновенной активации билетов
- Работы офлайн

## Использование

### Команды пользователя:
- `/start` - начало работы
- 🎫 Мероприятия - список событий
- 🎟 Мои билеты - купленные/подаренные билеты
- 💬 Поддержка - связь с поддержкой

### Команды администратора:
- ➕ Создать событие - новое мероприятие
- 🎁 Выдать билет - подарить билет пользователю
- 📊 Статистика - просмотр всей статистики
- ✅ Проверить билет - сканировать и активировать
- 👥 Добавить админа - новый администратор

## Статистика

Бот показывает:
- **Куплено** - билеты, полученные пользователями (тест)
- **Подарено** - билеты, выданные админами
- **Использовано** - активированные билеты на входе
- **Выручка** - потенциальная выручка (если бы оплата была реальной)

## Типы билетов

- 💳 **Куплен** - получен через "Купить билет" (бесплатно в тесте)
- 🎁 **Подарочный** - выдан администратором напрямую

## Переход на полную версию

Для добавления реальной оплаты:
1. Подключите ЮКасса или другую платежную систему
2. Замените тестовую оплату на реальную в `handlers/user_handlers.py`
3. Добавьте webhook для подтверждения платежей

См. директорию `lemon-tickets` для версии с реальной оплатой.
