# 📋 Проверка списков через VK сторис

## Как это работает

### Для пользователей:
1. Пользователь нажимает **"📋 Проверить список"** в меню
2. Указывает своё имя в VK (как оно отображается в профиле) или вводит его, если это первый раз
3. Выбирает мероприятие из доступных (только с привязанным VK-постом)
4. Отправляет скриншот сторис, где:
   - Отмечено его имя (@username)
   - Видна отметка сообщества (стикер тусовки)
   - Виден постер или название события
5. Бот анализирует скриншот через Gemini Vision AI и проверяет:
   - Есть ли отметка сообщества ✅
   - Есть ли постер события ✅
   - Совпадает ли имя автора с указанным ВК-аккаунтом ✅
6. Результат отправляется администраторам на подтверждение
7. **Дедупликация**: повторные скриншоты с тем же содержимым отклоняются по хешу

### Для администраторов:
1. При **создании мероприятия** админ указывает ссылку на пост VK сообщества
2. Бот валидирует ссылку через VK API (проверяет, что пост существует)
3. Система отправляет уведомления о проверках списков
4. Админ может одобрить или отклонить проверку

## Новые переменные окружения

```bash
# VK API токен сообщества (для получения информации о постах)
VK_API_TOKEN=your_vk_community_token_here

# Google Gemini API ключ (для анализа скриншотов)
GEMINI_API_KEY=your_google_gemini_api_key_here

# ID вашего VK-сообщества
VK_COMMUNITY_ID=your_vk_community_id_here
```

## Получение токенов

### VK API токен:
1. Зайдите в [VK Admin](https://vk.com/apps?act=manage)
2. Создайте новое приложение или откройте существующее
3. Скопируйте токен доступа сообщества
4. Токен должен иметь права на чтение постов (`wall:read`)

### Gemini API ключ:
1. Зайдите на [Google AI Studio](https://aistudio.google.com/apikey)
2. Нажмите "Get API Key"
3. Скопируйте ключ в переменную окружения

## Новые таблицы БД

- `user_vk_links` — привязка VK-аккаунтов пользователей
- `events_vk` — связь событий с VK-постами
- `list_checks` — записи проверок списков с результатами анализа
- `screenshot_hashes` — хеши скриншотов для дедупликации

## Новые модули

- `utils/vk_api.py` — интеграция с VK API
- `utils/gemini_vision.py` — анализ скриншотов через Gemini
- `utils/image_hash.py` — хеширование изображений
- `handlers/list_check_handlers.py` — обработка проверок списков

## Поток проверки

```
Пользователь нажимает "📋 Проверить список"
         ↓
Вводит/подтверждает имя в VK
         ↓
Выбирает мероприятие
         ↓
Отправляет скриншот сторис
         ↓
Бот считает хеш скриншота
         ↓
Проверка на дедупликацию
         ↓
Анализ через Gemini Vision:
  • Отметка сообщества?
  • Постер события?
  • Имя автора?
         ↓
Сравнение имени с VK-аккаунтом
         ↓
Сохранение результата в БД
         ↓
Уведомление администраторов
         ↓

```

## Безопасность и надёжность

- **Дедупликация по хешу**: предотвращает отправку одного скриншота несколько раз
- **AI-анализ**: Gemini проверяет подлинность элементов сторис
- **Валидация VK-ссылок**: проверка через VK API перед сохранением
- **Сравнение имён**: гибкое совпадение (с учётом пробелов, регистра, частичных совпадений)

## Текущие ограничения

- Требуется корректное имя в VK профиле для сравнения
- Gemini должно быть доступно (требуется интернет)
- VK API требует валидный токен сообщества
